# 钢铁咆哮 KV-44 · 横版坦克闯关（MVP）

以 KV44 坦克动画为风格参考的横版坦克闯关 Web 游戏。**零外部素材**——所有贴图（坦克、废墟、特效）由代码程序化生成，音效由 WebAudio 实时合成。

## 运行

```bash
npm install
npm run dev      # 打开终端输出的地址（默认 http://localhost:5173）
```

其他命令：

```bash
npm run typecheck   # TypeScript 检查
npm run build       # 产出 dist/ 静态文件，可任意托管
```

## 操作

**键鼠（桌面）：**

| 按键 | 动作 |
| --- | --- |
| A / D 或 ←→ | 移动 |
| W / 空格 | 跳跃 |
| 鼠标 | 炮塔瞄准 |
| 左键（可按住） | 开炮（范围伤害） |
| P | 暂停 |
| R | 结算后重开 |

**触屏（手机 / 平板，自动启用）：**

- 屏幕左半：按下出现浮动摇杆，左右移动（模拟量调速）
- 屏幕右半：按下出现瞄准摇杆，推杆控制炮塔方向，推过阈值自动连发（轻推可只瞄准不开火）
- 底部中央：跳跃按钮
- 右上角：暂停按钮；结算后点击屏幕任意处重开
- 竖屏时会提示横屏游玩

## 玩法

- 一张 5200px 横版关卡：尖刺坑、高台、修理箱、终点旗
- 敌人三种：巡逻坦克（抛物线炮击）、固定碉堡（三连发）、步兵（步枪）
- 击毁全部或抵达终点旗通关；被打空血失败

## 结构

```
src/
  main.ts               # Phaser 启动配置
  level.ts              # 关卡数据（地形/敌人/道具坐标，改这里调关卡）
  textureFactory.ts     # 程序化贴图（KV44 风格：炮塔眼睛、废墟背景）
  sfx.ts                # WebAudio 音效合成
  ballistic.ts          # 抛物线弹道解算
  ui/
    TouchController.ts  # 触屏双摇杆 + 跳跃/暂停按钮（仅触摸设备启用）
  scenes/
    BootScene.ts        # 生成贴图 → 菜单
    MenuScene.ts        # 标题画面
    GameScene.ts        # 主玩法场景（碰撞/特效/HUD/胜负）
  entities/
    PlayerTank.ts       # 玩家坦克（移动/瞄准/开炮/受伤）
    EnemyTank.ts        # 敌方坦克
    Bunker.ts           # 碉堡
    Soldier.ts          # 步兵
```
